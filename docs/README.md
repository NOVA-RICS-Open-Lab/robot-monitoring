# Docs

LaTeX sources, not rendered PDFs. Compile with `pdflatex` (run it twice, for the
table of contents) or paste into [Overleaf](https://overleaf.com).

- **RESULTS_REPORT.tex** — full write-up of the evaluation battery: methodology,
  per-test results and discussion.
- **EXPERIMENTAL_SETUP.tex** — the hardware/software environment the battery ran on.
- **WORKED_EXAMPLE.tex** — one single run traced end to end (Stage 1 -> Stage 2 ->
  Stage 3), with the real model output quoted.
